\subsection{Reproducing Previous Results}

The following results are generated using the new, improved codebase, with a subset of parameters that mimic the conditions for the previous paper \cite{LastDDPPaper}. As can be seen in \ref{fig:t_distribution_plot_reproduction}, using the same parameters, we achieved a similar convergence of the $t$ values distribution to a $\chi^2_{13}$ distribution.
