# Issue 013: Use injected significance on performance plot

**Status:** Open

## Statement

The significance performance plot must use ideal injected significance on its horizontal axis, as specified, rather than the mean number of injected signal events.

## Acceptance criteria

- The performance plot horizontal axis is labeled and populated with injected ideal significance $\sqrt{q_0}$.
- The same injected-significance calculation is used for every compatible signal dataset type that provides analytic signal and background distributions.
- Existing observed-significance curves and uncertainties are unchanged.
