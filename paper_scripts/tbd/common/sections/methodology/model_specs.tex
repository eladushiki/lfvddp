\paragraph{Model Specs}

As stated above, each network is a fully connected 3 layer \gls{nn} with Sigmoid activation function for the inner layer neurons. The full structure of our model can be observed in Figure~\ref{fig:model_implementation}. We chose $N=4$ for the number of neurons. Weights initialization is taken from a Xavier uniform, and biases are from a uniform distribution from the segment $[-0.3, 0.3]$.

Detector segments are initialized from a normal distribution with std of $1e-3$, and are clamped in each step if reaching either $\pm 1$ within a distance of $1e-6$.

Training batching is done with a single batch per train step, having all datasets as column vectors to allow for single pytorch operation for every arithmetic calculation.
