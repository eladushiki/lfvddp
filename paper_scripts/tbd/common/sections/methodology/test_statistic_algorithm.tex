\subsection{Description of the Algorithm}
The process is executed and evaluated as follows. The method for calculating a single $t$ value is described in Figure~\ref{alg:single_train_algorithm}.

\begin{figure*}
\caption{Single $t$ value stochastic calculation}
\label{alg:single_train_algorithm}
\begin{algorithmic}[1]

\Statex \textit{Variables in italics are user configurable}
\Statex % Purely for a clean visual separation

\Require Configuration of model internal parameters, $\nparam$ usage, dataset source and criteria, number of epochs

\State Load or generate a sample and randomly divide to $A^{SR}, B^{SR}$ of dimension $\mathit{k}$
\State Load or generate a sample and randomly divide to $A^{CR}, B^{CR}$ of dimension $\mathit{k}$
\State $\text{reference}^{SR} \gets A^{SR} + B^{SR}$ and same for $CR$

\If{\textit{should inject signal}}
    \State Inject the signal to $A^{SR}$
\EndIf

\State Numerator model $\gets \text{Model}(f, \nparam, \text{loss} = L^{\text{numerator}})$
\State Denominator model $\gets \text{Model}(f = 0, \nparam, \text{loss} = L^{\text{denominator}})$

\For{\textit{epoch} times}
    \State Train a step for each model
\EndFor

\State $t \gets -2 \cdot (\text{numerator model final loss}) + 2 \cdot (\text{denominator model final loss})$

\State Plot, document and save
\State \Return $t$

\end{algorithmic}
\end{figure*}

In cases in which the data is generated, new events are drawn every time the process is carried. In case the dataset is loaded, a subset of the background events are taken randomly from a larger amount that is loaded from the data source, and an artificial signal is added in the cases in which it is needed.

Repeating this procedure many times gives us a set of $t$ values, which, at a large repetition limit, should converge to a $\chi^2_r$. Graphs estimating the compatibility between the theoretical and the evident distributions are generated and appear in many instances here as well.

The background only distribution estimation is straight forward when the data is generated. When it is loaded, the background only reference $t$ value behavior is estimated from repeating the calculation while shuffling $\dataset{A}$ and $\dataset{B}$ samples in each region, with the signal, and re-partitioning them into samples of the original sizes. In this manner, on average, each sample carries the exact statistics of the reference distribution, which is composed of both. In this case, it's as if all signals are absent from the statistics.

Then, the same statistics are gathered with various shapes and intensities of signals. The significances of the median of the distribution, as well as the significance of the $\pm \sigma$ values from it, are estimated relative to the theoretical and evident background only distributions. Graphs displaying the progression of the detected significance of the detected signal as a function of the injected signal strength appear in many following cases.

\par\medskip\noindent{\color{blue}\raggedright\textbf{[Math note 15 -- the algorithm of Fig.~3]}\enspace
(a) Lines 7--8 train the numerator and denominator independently.

makes $q_0\ge0$ by construction.
 
(b) Line~3 builds the reference before the injection in line~5. With
real data the reference necessarily contains the signal, so the order
should be reversed; please check the code.
 
(c) The non-convergence filter (2.0\% of toys in Fig.~1, 3.8\% in
Fig.~6) is part of the test statistic. Define it, and apply it
