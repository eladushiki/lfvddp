\paragraph{Measuring Systematic Uncertainties}

We would like to learn about our system's effect of the samples, expressed via $\nparam$'s, in order to tell them apart from real signals. This can be done in an environment that is clean of signal. For our process, we introduce two additional samples that would be called the \gls{cr}. The original pair is now called the \gls{sr}, and the new physics is assumed to be expressed only there. Dataset names are elaborated in Table~\ref{table:division_of_data}.

The requirements from the \gls{cr} is as follows:
\begin{enumerate}
    \item The CR lacks new physics effects
    \item The system acts on \gls{sr} and \gls{cr} events in the same manner, as a function of $\anyevent$. In particular, their range is identical.
    \item All samples are disjoint.
\end{enumerate}

The \gls{cr} dataset pair would serve as a constraint to the nuisance parameters, which are incorporated to the \gls{sr} hypothesis as well.
