\subsection{Multiple Observables}

To expand the existing theory to cover for more observable dimensions and hence for more complex cuts in the future, we generalized the mechanism to work for any number of observable parameters describing each event, as in Section~\ref{sec:building_an_observed_dataset}. To this end, changes were added to the detector module, the dataset creation module and to the neural network architecture to handle richer data.
